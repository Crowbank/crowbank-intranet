## 📁 Project Structure Context

This documentation supports a Flask-based business management system with:
- **Business Domain**: Pet boarding, daycare, customer management
- **Tech Stack**: Python/Flask, PostgreSQL, HTMX, Tailwind CSS
- **Current Phase**: Database migration from legacy SQL Server to PostgreSQL
- **Future Goals**: AI integration, cloud deployment, payment processing
